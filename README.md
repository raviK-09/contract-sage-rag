# ContractSage

> AI-powered legal contract Q&A — ask questions about any contract in plain English and get answers with exact clause citations.

Runs entirely on local models via Ollama and sentence-transformers. No API keys or cloud costs required.

---

## Problem

Legal contracts are dense, jargon-heavy, and written for lawyers — not the people who actually sign them. Most people sign rental agreements, employment contracts, and NDAs without fully understanding what they're agreeing to.

ContractSage lets you upload any legal document and ask questions like:

- *"Can my landlord increase rent mid-term?"*
- *"What happens to my IP if I leave the company?"*
- *"What is the notice period to terminate this lease?"*

Every answer comes with exact page and clause citations so you can verify it yourself.

## Architecture

```
PDF / URL
    │
    ▼
Loader → Chunker → Embedder
                      │
                      ▼
                  ChromaDB (Vector Store)
                      │
              ┌───────┴────────┐
              │                │
         Dense Search      BM25 Search
         (semantic)        (keyword)
              │                │
              └───────┬────────┘
                      │ RRF Fusion + MMR Re-ranking
                      ▼
              Ollama LLM (Llama 3.1 8B)
                      │
              Citation Parser + Confidence Scorer
                      │
              Answer  /  Decline-to-Answer
```

**Retrieval**: Hybrid search combining dense vector similarity (ChromaDB) with BM25 keyword matching, fused using Reciprocal Rank Fusion (RRF). MMR re-ranking ensures diversity across retrieved chunks.

**Generation**: Answers generated by a local LLM with a structured prompt requiring `[Source N]` citations on every claim.

**Confidence**: A three-signal score (retrieval quality + context coverage + citation usage) determines whether to return the answer or decline. Prevents hallucinations on out-of-scope questions.

**Evaluation**: Custom RAGAS-style metrics — context precision, recall, faithfulness, answer relevance, keyword hit rate, and source accuracy.

## Quick Start

### Prerequisites

- Python 3.11+
- [Ollama](https://ollama.com) installed

### 1. Pull the LLM model

```bash
ollama pull llama3.1:8b
```

### 2. Install dependencies

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate

pip install -e .
```

### 3. Configure

```bash
cp .env.example .env
# Edit .env if you want to change defaults (port, model name, etc.)
```

### 4. Seed sample contracts and start

```bash
# Load the 5 sample contracts into the vector store
python scripts/seed_data.py

# Terminal 1 — API backend
uvicorn app.api.main:app --reload --port 8000

# Terminal 2 — Streamlit UI
streamlit run app/ui/app.py
```

Open **http://localhost:8501** for the UI or **http://localhost:8000/docs** for the interactive API docs.

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/health` | Ollama status, model availability, chunk count |
| `POST` | `/ingest/pdf` | Upload a PDF contract |
| `POST` | `/ingest/url` | Ingest from a public URL |
| `GET` | `/documents` | List all ingested documents |
| `DELETE` | `/documents/{source}` | Remove a document |
| `POST` | `/query` | Ask a question, returns cited answer |

Full interactive docs at **http://localhost:8000/docs**

## Tech Stack

| Component | Choice | Notes |
|-----------|--------|-------|
| LLM | Ollama + Llama 3.1 8B | Local, no API cost, OpenAI-compatible interface |
| Embeddings | all-MiniLM-L6-v2 | 80 MB, CPU-friendly, strong baseline |
| Vector Store | ChromaDB | Persistent, zero setup, metadata filtering |
| Sparse Retrieval | BM25 (rank-bm25) | Exact term matching for legal references |
| Framework | LangChain | Modular LLM/embedding abstraction |
| API | FastAPI | Async, auto-generated OpenAPI docs |
| UI | Streamlit | Rapid prototyping for ML dashboards |

## Running the Evaluation

With the API running:

```bash
python scripts/run_evaluation.py
```

This runs 12 curated questions against the loaded contracts and outputs:

- Context Precision, Context Recall
- Faithfulness, Answer Relevance, Keyword Hit Rate
- Source Accuracy, Decline Accuracy

Results saved to `data/eval_results/` as JSON and CSV.

## Switching to a Cloud LLM

The LLM interface uses LangChain's `BaseChatModel` — swapping providers is a one-line change in `app/generation/llm_client.py`:

```python
# Local (default)
from langchain_ollama import ChatOllama
return ChatOllama(model="llama3.1:8b", base_url="http://localhost:11434")

# OpenAI
from langchain_openai import ChatOpenAI
return ChatOpenAI(model="gpt-4o", api_key="sk-...")

# Anthropic
from langchain_anthropic import ChatAnthropic
return ChatAnthropic(model="claude-sonnet-4-20250514", api_key="sk-ant-...")
```

Everything else — prompts, citation parsing, confidence scoring — stays the same.
